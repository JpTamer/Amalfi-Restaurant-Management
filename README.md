# Amalfi — Full-Stack Restaurant Management 🍽️

Welcome to Amalfi, a full-stack restaurant application built with React, Node.js, and PostgreSQL. Amalfi lets customers view a delicious Italian menu, add items to their cart, review and place orders, and track the progress of orders in real time.

### 🛠️ Tech Stack
* **Front-End:** React, Vite, JavaScript (ES6+), Tailwind CSS
* **Back-End / API:** Node.js, Express.js
* **Database:** PostgreSQL
* **Routing:** React Router

### 🚀 Key Features
* **Responsive UI:** Built with React and Tailwind to ensure a seamless experience across devices.
* **RESTful APIs:** Custom endpoints developed with Express.js to handle menus, orders, and operational data.
* **Database-Driven:** Robust PostgreSQL schema design for secure and efficient data management.
* **Order Tracking:** Monitor the status and progress of placed orders in real-time.

## Getting Started

### Prerequisites

- npm (v9+ recommended) or yarn

### Installation

```bash
git clone https://github.com/JpTamer/FirstReactProject.git
cd FirstReactProject
npm install
```

### Running Locally (Vite)

```bash
npm run dev
```

Then open the URL printed in the terminal, usually [http://localhost:5173](http://localhost:5173).

## Usage

1. **Explore the Menu:** Browse Italian specialties.
2. **Add to Cart:** Click to add items.
3. **Review & Place Order:** Review selections and confirm your order.
4. **Track Progress:** Watch your order being prepared and delivered.

## Technologies Used

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS — Utility-first CSS framework for rapid UI development
- React Router: For client-side routing and navigation.

### Tailwind CSS Setup

This project uses [Tailwind CSS](https://tailwindcss.com/) for styling. Tailwind is already installed and configured via `tailwind.config.js` and imported in `src/index.css`. You can customize your design by editing utility classes in your components.

To learn more about customizing Tailwind, visit their [documentation](https://tailwindcss.com/docs/installation).

## Deployment

This project is deployed at: [https://amalfi-lilac.vercel.app](https://amalfi-lilac.vercel.app)

> **Note on Live Demo:** The backend and database are hosted on a free tier. If the service has been inactive, it may experience a "cold start" resulting in a 30–50 second delay when initially fetching the menu or processing the first order. 

To deploy your own version, you can use services like Vercel, Netlify, or any static hosting that supports Vite builds.
